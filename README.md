# Z

一个本地优先的轻量动态发布页面。使用纯 HTML、CSS 和 JavaScript，无需框架、第三方运行依赖或构建步骤。

## 功能

- 发布最多 280 字的文字动态，支持实时字数统计与空白校验
- 最新动态优先展示，显示本地化发布时间
- 使用 Local Storage 保存数据，刷新后自动恢复
- 浅色淡雅界面、磨砂导航、柔和圆角与细腻阴影
- 本地抽象主视觉与原创 SVG 插画，不依赖外部图片地址
- 已有的滚动显现、轻微视差与卡片交错入场，可一键关闭装饰动效
- 支持系统“减少动态效果”偏好
- 适配桌面与手机，提供输入错误、存储异常和发布成功反馈
- 用户内容按纯文本渲染，避免 HTML 注入

## 本地运行

需要 Node.js 18 或更高版本，无需安装依赖。

```powershell
npm start
```

打开 <http://127.0.0.1:8000>。

也可以使用任意静态 HTTP 服务托管本目录。请不要直接通过 `file://` 打开，因为浏览器会限制 ES Modules。

## 测试

```powershell
npm test
```

测试使用 Node.js 内置的 `node:test`，覆盖数据读写、输入校验、时间排序、损坏数据恢复和存储异常。

## 本地数据说明

动态保存在当前浏览器、当前站点来源下的 `z.posts.v1` 存储键中：

- 不上传服务器，不在不同浏览器或设备之间同步
- 清理浏览器站点数据会删除动态
- 更换端口或域名会被视为不同站点来源，原数据不会自动迁移
- 存储不可用时，尚未发布的输入会保留在文本框中

## 文件结构

```text
├── index.html             # 页面语义结构
├── styles.css             # 浅色界面、响应式布局与现有动效
├── app.js                 # 表单交互、时间线渲染与动效控制
├── images/                # 本地装饰插画
├── storage.js             # Local Storage 数据层
├── server.js              # 零依赖本地静态预览服务
├── tests/storage.test.js  # 数据层单元测试
└── package.json           # 启动与测试命令
```
